| Use Case Specification      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Use Case Name               | Re-Order Stock                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Actor(s)                    | GIFTS-4-U Staff (primary), Hong Kong Novelty Goods Inc. (secondary)                                                                                                                                                                                                                                                                                                                                                                                                     |
| Summary Description         | GIFTS-4-U restocks blank products (e.g. white mugs, white teddy bears) by sending a purchase order to Hong Kong Novelty Goods Inc. The purchase order is created automatically when a product's stock reaches the re-order threshold set by the CEO, or manually by a staff member. The supplier confirms whether it can fulfil the order, ships it complete and updates its status until it reaches the GIFTS-4-U warehouse in Middelburg, where the stock is updated. |
| Priority                    | Must-Have                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Status                      | Uncommenced                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Pre-Condition(s)            | The product is registered in the system under a unique SKU and is supplied by Hong Kong Novelty Goods Inc.                                                                                                                                                                                                                                                                                                                                                              |
|                             | The CEO has set a re-order threshold for the product (FR6, FR50).                                                                                                                                                                                                                                                                                                                                                                                                       |
|                             | The Hong Kong Novelty Goods Inc. supplier service is connected to the system and can receive purchase orders.                                                                                                                                                                                                                                                                                                                                                           |
|                             | For a manual re-order, the staff member is logged in to the Control Tower.                                                                                                                                                                                                                                                                                                                                                                                              |
| Post-Condition(s)           | The complete ordered quantity has arrived at the GIFTS-4-U warehouse and has been added to the stock of the SKU (FR8, FR34).                                                                                                                                                                                                                                                                                                                                            |
|                             | The purchase order has the status "Received at Warehouse" and every status change is stored with a timestamp (FR14).                                                                                                                                                                                                                                                                                                                                                    |
|                             | The purchase order, its status history and arrival date are visible in the Hong Kong section of the Control Tower (FR13).                                                                                                                                                                                                                                                                                                                                               |
| Basic Path                  | 1. The system detects that the warehouse stock of a product has reached the re-order threshold set by the CEO (FR6, FR7, FR50).                                                                                                                                                                                                                                                                                                                                         |
|                             | 2. The system creates a purchase order for the product with the SKU, quantity and requested date (FR7, FR12).                                                                                                                                                                                                                                                                                                                                                           |
|                             | 3. The system sends the purchase order to the Hong Kong Novelty Goods Inc. supplier service (FR12).                                                                                                                                                                                                                                                                                                                                                                     |
|                             | 4. Hong Kong Novelty Goods Inc. answers the purchase order with "can fulfil" and sets its status to "Confirmed" (FR14, FR32).                                                                                                                                                                                                                                                                                                                                           |
|                             | 5. The system calculates the expected arrival date as 2 weeks of transport plus any delay reported by the supplier (FR33).                                                                                                                                                                                                                                                                                                                                              |
|                             | 6. The system shows the purchase order with its status and expected arrival date in the Hong Kong section of the Control Tower (FR13).                                                                                                                                                                                                                                                                                                                                  |
|                             | 7. Hong Kong Novelty Goods Inc. updates the purchase order status to "In Production" (FR14).                                                                                                                                                                                                                                                                                                                                                                            |
|                             | 8. Hong Kong Novelty Goods Inc. ships the complete order and updates the status to "Shipped" (FR14, FR34).                                                                                                                                                                                                                                                                                                                                                              |
|                             | 9. The system tracks the inbound shipment against its expected arrival date (FR11).                                                                                                                                                                                                                                                                                                                                                                                     |
|                             | 10. The shipment clears Dutch customs and DHL delivers it to the GIFTS-4-U warehouse in Middelburg; Hong Kong Novelty Goods Inc. updates the status to "Received at Warehouse" (FR14).                                                                                                                                                                                                                                                                                  |
|                             | 11. The system adds the full ordered quantity to the warehouse stock of the SKU (FR8).                                                                                                                                                                                                                                                                                                                                                                                  |
|                             | 12. The use case ends.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Alternative Paths           | A1. Manual re-order by staff (replaces steps 1-2):                                                                                                                                                                                                                                                                                                                                                                                                                      |
|                             | A1.1 A GIFTS-4-U staff member opens the Control Tower and chooses to re-order a product.                                                                                                                                                                                                                                                                                                                                                                                |
|                             | A1.2 The staff member enters the SKU, quantity and requested date.                                                                                                                                                                                                                                                                                                                                                                                                      |
|                             | A1.3 The system creates the purchase order (FR12) and the use case continues at step 3.                                                                                                                                                                                                                                                                                                                                                                                 |
|                             | A2. Urgent purchase order (at step A1.2):                                                                                                                                                                                                                                                                                                                                                                                                                               |
|                             | A2.1 The staff member marks the purchase order as urgent, e.g. during the Christmas rush or when the stock is needed for a B2B order (FR18).                                                                                                                                                                                                                                                                                                                            |
|                             | A2.2 The system sends the purchase order with the urgent flag and shows the flag in the Hong Kong section; the use case continues at step 4.                                                                                                                                                                                                                                                                                                                            |
|                             | A3. Supplier cannot fulfil (at step 4):                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|                             | A3.1 Hong Kong Novelty Goods Inc. answers the purchase order with "cannot fulfil" and sends a delay message (FR32).                                                                                                                                                                                                                                                                                                                                                     |
|                             | A3.2 The system calculates the expected arrival date as 2 weeks of transport plus the reported delay (FR33).                                                                                                                                                                                                                                                                                                                                                            |
|                             | A3.3 The use case continues at step 6, with the delay shown on the purchase order in the Hong Kong section (FR13).                                                                                                                                                                                                                                                                                                                                                      |
| Exception Paths             | E1. Supplier reports an exception (at any step from 4 to 10):                                                                                                                                                                                                                                                                                                                                                                                                           |
|                             | E1.1 Hong Kong Novelty Goods Inc. reports an exception on the purchase order: out of stock, unable to fulfil (e.g. a very large order during the Christmas rush), stuck in customs, or an incident such as a fire (FR15).                                                                                                                                                                                                                                               |
|                             | E1.2 The system records the exception on the purchase order and shows it in the Hong Kong section of the Control Tower (FR13).                                                                                                                                                                                                                                                                                                                                          |
|                             | E1.3 If the supplier reports a delay, the system adds it to the expected arrival date (FR33).                                                                                                                                                                                                                                                                                                                                                                           |
|                             | E1.4 When the supplier resolves the exception and updates the status (FR14), the use case continues at the matching step; otherwise the use case ends without the stock being updated.                                                                                                                                                                                                                                                                                  |
|                             | E2. Shipment is late (at step 9):                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                             | E2.1 The expected arrival date passes without the status "Received at Warehouse".                                                                                                                                                                                                                                                                                                                                                                                       |
|                             | E2.2 The system flags the purchase order as late and sends an alert to GIFTS-4-U staff (FR11).                                                                                                                                                                                                                                                                                                                                                                          |
|                             | E2.3 The system emails Hong Kong Novelty Goods Inc. about the late shipment (FR16).                                                                                                                                                                                                                                                                                                                                                                                     |
|                             | E2.4 The use case continues at step 9.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                             | E3. Supplier service error (at step 3):                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|                             | E3.1 The purchase order cannot be delivered to the Hong Kong Novelty Goods Inc. supplier service.                                                                                                                                                                                                                                                                                                                                                                       |
|                             | E3.2 The system shows the error on the supplier's page in the Control Tower (FR17) and the use case ends without the purchase order being sent.                                                                                                                                                                                                                                                                                                                         |
| Business Rules              | B1. Re-order thresholds are set per product by the GIFTS-4-U CEO (FR6, FR50).                                                                                                                                                                                                                                                                                                                                                                                           |
|                             | B2. A purchase order is created automatically as soon as a product's stock reaches its re-order threshold (FR7).                                                                                                                                                                                                                                                                                                                                                        |
|                             | B3. Every purchase order contains the SKU, quantity and requested date, and is sent through the system instead of by email (FR12).                                                                                                                                                                                                                                                                                                                                      |
|                             | B4. The supplier answers every purchase order with "can fulfil" or "cannot fulfil"; a "cannot fulfil" answer includes a delay message (FR32).                                                                                                                                                                                                                                                                                                                           |
|                             | B5. Expected arrival date = 2 weeks of transport + any delay reported by the supplier (FR33).                                                                                                                                                                                                                                                                                                                                                                           |
|                             | B6. A purchase order is shipped complete or not at all; partial shipments are not accepted (FR34).                                                                                                                                                                                                                                                                                                                                                                      |
|                             | B7. A purchase order's status is one of: Confirmed, In Production, Shipped, Received at Warehouse (FR14).                                                                                                                                                                                                                                                                                                                                                               |
|                             | B8. Warehouse stock is only updated once the purchase order reaches "Received at Warehouse" (FR8).                                                                                                                                                                                                                                                                                                                                                                      |
|                             | B9. A purchase order may be marked urgent; B2B orders take priority over B2C orders (FR18).                                                                                                                                                                                                                                                                                                                                                                             |
| Non-Functional Requirements | NFR2. The system shall identify products by their SKU (a list of unique and standardized identifiers).                                                                                                                                                                                                                                                                                                                                                                  |
|                             | NFR4. The system shall have an adjustable polling time for warehouse stock checks (used to detect when a re-order threshold is reached).                                                                                                                                                                                                                                                                                                                                |
|                             | NFR5. The system shall store every purchase order status change with a timestamp.                                                                                                                                                                                                                                                                                                                                                                                       |
|                             | NFR7. The system's time zone shall be standardized to CET (applies to requested and expected arrival dates, even though the supplier is in Hong Kong).                                                                                                                                                                                                                                                                                                                  |
|                             | NFR12. The system shall contain a section for each organization in the supply chain (the Hong Kong section).                                                                                                                                                                                                                                                                                                                                                            |
|                             | NFR13. The system shall allow staff members limited access to the Control Tower.                                                                                                                                                                                                                                                                                                                                                                                        |
