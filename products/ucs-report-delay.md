| Use Case Specification      |                                                                                                                                                                                                                                                                                                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Use Case Name               | Report Delivery Issue & Estimated Delay                                                                                                                                                                                                                                                                                                                       |
| Actor(s)                    | DHL                                                                                                                                                                                                                                                                                                                                                           |
| Summary Description         | DHL reports an issue with an order in transit together with an estimated delay. The system adds the delay to the order's estimated delivery time, alerts GIFTS-4-U Staff, adds a task to their task list and notifies the customer. An international order held at a border triggers its own alert, and an issue on a B2B order also triggers an email alert. |
| Priority                    | Must-Have                                                                                                                                                                                                                                                                                                                                                     |
| Status                      | Uncommenced                                                                                                                                                                                                                                                                                                                                                   |
| Pre-Condition(s)            | The order is in transit with DHL and is listed in the orders in transit section (FR54).                                                                                                                                                                                                                                                                       |
|                             | The system has sent DHL the order details, including the order number, route, SKUs and expected delivery time (FR51).                                                                                                                                                                                                                                         |
|                             | The order has an estimated delivery time.                                                                                                                                                                                                                                                                                                                     |
| Post-Condition(s)           | The issue and the estimated delay are recorded against the order, and the order's estimated delivery time includes the delay (FR56).                                                                                                                                                                                                                          |
|                             | GIFTS-4-U Staff have received a delay alert and have a new task for the order on their task list (FR3, FR4).                                                                                                                                                                                                                                                  |
|                             | The customer has been notified of the delay and can see the updated delivery time (FR20, FR21).                                                                                                                                                                                                                                                               |
| Basic Path                  | 1. DHL reports an issue with an order in transit, including a description of the issue and an estimated delay (FR52, FR57).                                                                                                                                                                                                                                   |
|                             | 2. The system matches the report to the order in transit using its order number.                                                                                                                                                                                                                                                                              |
|                             | 3. The system records the issue and the estimated delay against the order, with a timestamp.                                                                                                                                                                                                                                                                  |
|                             | 4. The system adds the estimated delay to the order's estimated delivery time (FR56).                                                                                                                                                                                                                                                                         |
|                             | 5. The system sends a delay alert to GIFTS-4-U Staff (FR3).                                                                                                                                                                                                                                                                                                   |
|                             | 6. The system adds a new task for the delayed order to the staff task list (FR4).                                                                                                                                                                                                                                                                             |
|                             | 7. The system notifies the customer that the shipment is delayed and shows the updated delivery time (FR20, FR21).                                                                                                                                                                                                                                            |
|                             | 8. The system shows the issue and the updated delivery time for the order in the orders in transit section (FR54).                                                                                                                                                                                                                                            |
| Alternative Paths           | A1. International order held at a border: at step 3, if the order is flagged as international (FR1) and DHL reports that it is held at the Chinese or Dutch border, the system also sends a separate border-hold alert to GIFTS-4-U Staff (FR53). The use case continues at step 4.                                                                           |
|                             | A2. B2B order: at step 7, if the order is a B2B order, the system also sends an automatic email alert about the issue (NFR1). The use case continues at step 8.                                                                                                                                                                                               |
| Exception Paths             | E1. Unknown order: at step 2, if the order number does not match an order in transit, the system rejects the report and returns an error to DHL. No order is changed and the use case ends.                                                                                                                                                                   |
|                             | E2. No estimated delay: at step 1, if DHL reports an issue without an estimated delay, the system records the issue but leaves the estimated delivery time unchanged. It still alerts GIFTS-4-U Staff and adds a task so they can get an estimate from DHL (FR3, FR4). The use case ends.                                                                     |
| Business Rules              | B1. The estimated delay reported by DHL is added to the order's current estimated delivery time (FR56).                                                                                                                                                                                                                                                       |
|                             | B2. Orders from Hong Kong are automatically flagged as international (FR1).                                                                                                                                                                                                                                                                                   |
|                             | B3. The border-hold alert is only sent for international orders held at the Chinese or Dutch border (FR53).                                                                                                                                                                                                                                                   |
|                             | B4. GIFTS-4-U prioritizes B2B orders over B2C orders, so an issue on a B2B order is also escalated by email.                                                                                                                                                                                                                                                  |
| Non-Functional Requirements | NFR1. The system shall automatically send an alert in the form of an email when any issues arise with B2B orders.                                                                                                                                                                                                                                             |
|                             | NFR7. The system's time zone must be standardized to CET.                                                                                                                                                                                                                                                                                                     |
